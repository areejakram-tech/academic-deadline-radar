# academic-deadline-radar
Automated CLI tracker for university scholarships and research deadlines with Markdown report generation.
## Features
- Track university scholarships, grants, and research conference deadlines
- Automatic urgency classification (`CRITICAL`, `HIGH PRIORITY`, `ON TRACK`)
- Persistent JSON data storage
- One-click automated Markdown checklist export (`DEADLINE_CHECKLIST.md`)

## How to Run
1. Make sure Python 3 is installed.
2. Run the script in terminal:
   ```bash
   python deadline_radar.py
   ```
